# todo-app-node

A simple ToDo web application using event sourcing.

## Building the application

```pwsh
npm install
npm run build
```

## Linting and formatting the application

```pwsh
npm run biome:check
```

```pwsh
npm run biome:fix
```

## Testing the application

```pwsh
npm test
```

## Running the application

```pwsh
npm install
npm run dev
```
